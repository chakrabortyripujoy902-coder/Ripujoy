# Social Connect

A lightweight WhatsApp-like chat prototype with:
- Phone + OTP authentication (demo OTP shown in UI)
- User profile registration (Name + Country)
- 1:1 direct chat
- Group chats
- File sharing (images, videos, audios, and generic files)
- Realtime messaging with Socket.IO
- White + light purple UI theme

## Run

```bash
npm install
npm start
```

Open `http://localhost:3000`
